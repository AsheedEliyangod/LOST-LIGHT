# LOST LIGHT

*A 2D atmospheric adventure game built with Unity 6.*

LOST LIGHT is an atmospheric 2D adventure developed by **AE Studios**. Explore a mysterious, dark world where light is more than a source of visibility — it is a tool for survival, exploration, and combat.

## 🎮 Game Overview

The world of LOST LIGHT is filled with shadowy environments, ancient ruins, hidden paths, and dangerous creatures. Players must learn to control their lantern's energy and use light strategically to overcome obstacles and progress through the world.

### ✨ Core Features

- **Lantern System** — Toggle your lantern and manage its energy.
- **Light Intensity Modes** — Switch between normal and strong light, each with different energy consumption.
- **Exploration** — Discover atmospheric environments and hidden paths.
- **Combat** — Face shadow creatures that can pursue and attack the player.
- **Light-Based Mechanics** — Use light to stun or repel enemies and reveal hidden elements.
- **Platforming** — Navigate the environment using responsive movement and variable jump height.
- **Energy Management** — Balance lantern usage with the energy available to you.

## 🕹️ Controls

## 🚀 Getting Started

To explore the project locally:

1. Clone or download this repository.
2. Open Unity Hub.
3. Select **Add Project from Disk**.
4. Choose the downloaded LOST LIGHT project folder.
5. Open the project using a compatible Unity 6 installation.
6. Open the main gameplay scene from `Assets/Scenes/Forest_01.unity`.

Unity may take some time to import assets when opening the project for the first time.
